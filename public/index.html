🚨 应急疏散快照

输入事件时刻并勾选一个或多个出口区域：按当前校验模式的实际路线还原每位演员当时的位置（区域等待 / 停留 / 通道行进中）。 位于通道者先按原方向走完剩余路程，再从到达区域按事件时刻之后的封闭时段计算到任一出口的最早疏散路线；位于区域者从事件时刻直接计算； 因不可达链无法确定位置的演员单独标为位置未知，不做猜测。结果按最晚撤离优先排序，导出的 Markdown 报告会追加同一快照。

🔗 跨演员口令依赖

在两条口令之间维护「前置口令完成（当前模式下实际到达 + 停留时长）后至少等待 N 秒，后置口令才可实际出发」的有向约束（两条口令可属于不同演员）。 保存前会检查整张依赖图，成环时拒绝写入并提示闭环口令链。下方结果按当前校验模式即时重算： ✅ 满足、❌ 违约（附相差秒数）、❓ 无法判定（任一端口令不可达或无实际出发时刻）。删除口令会自动清理相关依赖。

👔 演员换装核查

为同一演员相邻两条到位口令（一个区段）登记换装任务：换装区域 + 所需整数秒数，每个区段最多一项。 核查按当前校验模式取得该区段的实际出发时刻，依次计算「起点 → 换装区」与「换装完成 → 终点」两段最早路线—— 两段均计入通道封闭造成的等待或绕行（第二段自换装完成时刻起算），不是静态最短耗时的简单相加。 结果给出换装完成时刻、最终到达时刻、相对下一口令的余量与 ✅ 准时 / ❌ 迟到 / ⛔ 不可达状态； 换装核查仅评估该区段，不改写原走位校验结果。删除关联口令或区域时任务自动清理，切换模式或修改区域连接后即时重算。

🎬 现场走位复盘

上传现场记录 UTF-8 CSV（表头固定为 演员姓名,角色,实际时刻,实际区域）：系统仅解析现有演员（姓名 + 角色）与现有区域（名称）， 未知或歧义的演员 / 区域、时刻格式错误逐行报错且不参与对齐。服务端按演员将实际记录与计划口令做 保持先后顺序的一对一最优对齐（两侧分别按计划时刻/口令 ID、实际时刻/CSV 行号排序）： 配对成本为时差绝对值，区域不符加 300，每条漏执行口令或多余记录加 180； 成本相同时先取配对数多者，再取实际记录行号序列字典序较小者，同一记录不重复匹配。 复盘为只读分析，不会改写任何走位数据；时刻支持秒数（如 90）或 mm:ss（如 01:30）。

👁 观众视线遮挡检查

以整数厘米维护观众点（x、y、眼高）、舞台目标（x、y、目标高）与轴对齐矩形遮挡物（x、y、宽、深、高）。 服务端对每条「观众 → 目标」视线段精确裁剪其与各矩形投影的相交参数区间（slab 法分数运算，边界接触算相交，不是只测矩形中心或采样点）； 相交区间内视线高度 ≤ 遮挡物高度（等于也算被挡）即判定遮挡，按最小进入参数确定首挡物， 并给出使视线严格越过全部相交遮挡物的最小整数目标高度与建议抬高量。

🏗 吊挂布景载荷核算

维护同一横梁上的吊点（横坐标、额定载荷）与吊挂件（重量、重心横坐标、左右吊点、生效时段 [起, 止)）。 每件按力矩平衡分担到两吊点：左点分担 = 重量 ×（右点横坐标 − 重心横坐标）÷ 吊点间距，右点分担 = 重量 ×（重心横坐标 − 左点横坐标）÷ 吊点间距； 累计与比较全程使用有理数（分数）精确运算——累计载荷恰好等于额定载荷不算超额，临界值不会因舍入被误判。 同一秒结束先于开始（半开时段不叠加），逐吊点输出峰值载荷与超额区间（载荷 > 额定载荷），首尾相接的连续超额自动合并； 删除被吊挂件引用的吊点会被拒绝。
